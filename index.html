02 · 왜 저희인가

다른 업체가 돈 주고 사 오는 것을,
저희는 직접 만듭니다.

리워드 마케팅이 뭔지 말로 설명하는 업체는 많습니다.
저희는 실물을 보여드립니다 — 저희가 직접 운영하는 리워드 플랫폼입니다.

사장님 가게가 전국 리워드 앱 사용자의 미션이 됩니다.

사장님 가게를 미션으로 올리면, 전국의 리워드 앱 사용자들에게 전달됩니다. 사용자는 포인트를 받기 위해 키워드를 검색하고 → 사장님 가게를 찾아 → 저장하고, 알림을 켜고, 길찾기를 누릅니다.

네이버 입장에서는 실제 사용자가 검색해서 찾아온 진짜 기록입니다. 이게 매일, 정해진 만큼, 꾸준히 쌓입니다.
